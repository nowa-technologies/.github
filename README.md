# .github

Org-wide config + profile for `nowa-technologies` GitHub Organization.

## Contents

- [`profile/README.md`](./profile/README.md) — Public profile shown on https://github.com/nowa-technologies
- [`CONTRIBUTING.md`](./CONTRIBUTING.md) — Rules, conventions, workflow for all members
- [`SETUP.md`](./SETUP.md) — Local tool setup guide for new members
- `.gitignore` — Template ignore patterns

## How GitHub uses this repo

Files in this special `.github` repo serve as org-wide defaults:
- `CONTRIBUTING.md` auto-suggested when members create PRs in any org repo
- `profile/README.md` displays on org's public page

→ Maintain rules in one place, apply org-wide.
